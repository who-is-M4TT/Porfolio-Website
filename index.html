Categories :

Home Lab

This project demonstrates the design and implementation of a hybrid enterprise-style infrastructure environment built within a homelab. The objective of the project was to simulate a small business IT environment and showcase practical systems administration, networking, and security architecture skills beyond certification-level knowledge.

The environment integrates on-premises infrastructure hosted on Proxmox with hybrid identity services using Microsoft Entra ID. Core components include Active Directory Domain Services for centralized authentication, pfSense for firewall and network boundary protection, and TrueNAS for centralized storage using ZFS. The project focuses on enterprise design principles such as identity-based access control, defense-in-depth security, and operational planning including logging, monitoring, and backup strategy.

This project highlights practical experience with enterprise infrastructure technologies including virtualization, hybrid identity management, network security, and centralized storage. The environment was fully documented with architecture diagrams and technical documentation to demonstrate real-world infrastructure design and operational considerations.
Technologies used in this project include Proxmox VE, pfSense, Windows Server Active Directory, Microsoft Entra ID, Azure AD Connect, TrueNAS, and Twingate secure remote access.
