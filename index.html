RetailOps Cloud-Native Platform

Cloud-native retail integration on Microsoft Azure

Created By:

Thit Lwin Oo

Date:

Aug 2025

Category:

Cloud / Azure

Client:

SmartRetail Inc. (scenario)

Overview

A cloud-native retail integration system that provides real-time stock tracking, automated reordering when inventory runs low, and end-to-end observability. Three Dockerized microservices run on an Ubuntu VM and hand work off to serverless Azure Functions through an Azure Storage Queue.

Architecture

  • Microservices (Docker Compose): React frontend dashboard, Node.js product-service and inventory-api.
  • Event-driven reorders: inventory-api publishes low-stock events to the stock-events Storage Queue; a Queue-triggered Function processes them and issues the reorder (supplier call simulated).
  • HTTP trigger: manual reorder endpoint for on-demand restocking.
  • Timer trigger: scheduled daily stock summary.
  • Observability: Application Insights collects frontend and backend telemetry.
  • Security: API-key protection on all endpoints and CORS restricted to known origins.

Tech Stack

  • Azure Storage Queue
  • Application Insights

Hybrid Enterprise Infrastructure Homelab

Enterprise-style hybrid infrastructure in a homelab

Created By:

Thit Lwin Oo

Date:

16/2/2026

Category:

Home Lab

Overview

This project demonstrates the design and implementation of a hybrid enterprise-style infrastructure environment built within a homelab. The objective was to simulate a small business IT environment and showcase practical systems administration, networking, and security architecture skills beyond certification-level knowledge.

The environment integrates on-premises infrastructure hosted on Proxmox with hybrid identity services using Microsoft Entra ID. Core components include Active Directory Domain Services for centralized authentication, pfSense for firewall and network boundary protection, and TrueNAS for centralized storage using ZFS. The project focuses on enterprise design principles such as identity-based access control, defense-in-depth security, and operational planning including logging, monitoring, and backup strategy.

This project highlights practical experience with enterprise infrastructure technologies including virtualization, hybrid identity management, network security, and centralized storage. The environment was fully documented with architecture diagrams and technical documentation to demonstrate real-world infrastructure design and operational considerations.

Tri-WAN Tower: Secure, Resilient Network for an 8-Story Mixed-Use Building

Enterprise network design based on a real building (sanitized)

Created By:

Thit Lwin Oo

Date:

Nov 2026

Category:

Network Design

Scope:

2 enterprise + 6 residential floors

Overview

A complete network design for an 8-story mixed-use building with two enterprise floors and six residential floors, plus door and elevator systems, 28 CCTV cameras, a DMZ and central services. The project includes architecture and security documentation, design-decision records, baseline device configs for the core and all eight floor switches, and VLAN, IP, port and equipment tables.

Design Highlights

  • Triple-ISP edge: three bridge-mode modems on diverse entry routes; WAN 1 pinned for mail, VPN and DMZ, with WAN 2 and 3 load-balanced.
  • No single point of failure: an HA firewall pair (active/standby) and a stacked L3 distribution pair; every floor, the server block and the firewalls are dual-homed.
  • Access layer: a PoE+ switch on every floor with 2×10G LACP uplinks, one to each core switch, feeding 16 Wi-Fi 6 APs.
  • Segmentation: 18 VLANs, including one isolated VLAN per residence floor, an AD-managed enterprise network with 802.1X Wi-Fi, guest Wi-Fi, and non-routed door/elevator VLANs.
  • Isolated CCTV zone: 28 cameras behind the firewall with deny-all inbound, NTP only, and VPN-only remote viewing.
  • Hardening and management: port security, DHCP snooping, protected ports and tamper-alarmed cabinets; a single MFA VPN admin path to a jump host on the management VLAN.
  • Resilience: UPS on every rack plus a generator with ATS, along with documented monitoring, backups, runbooks and a test plan.
